# Desk Setup Switcher 0.0.10 — keyboard repeat fix

This is a user-requested **development prerelease**, separate from the planned supported v0.1.0 public beta. It contains the same keyboard-repeat correction that was installed and reported working by a user. It does not establish the supported macOS 14 Sonoma lifecycle or hardware rollback.

## Changes

- Fix keyboard Apply reporting success after only saving preferences while active repeat timing stayed unchanged.
- Read active repeat speed/delay during Capture and confirm both saved preferences and active values during Apply.
- Plan a needed active change even when the saved preference already matches the profile.
- Preserve and independently restore the original saved and active values after a partial failure, including a previously absent preference key.
- Keep existing profiles, inclusion choices, and the seven-setting Sound/Keyboard scope. Repeat controls remain experimental; unavailable controls and native repeat Off are not guessed.

## Package and verification

The release contains only the universal `arm64`/`x86_64` DMG and its adjacent SHA-256 checksum. It is **Developer ID-unsigned and not notarized**; an ad-hoc signature provides code integrity rather than publisher authentication. Exact-source automated app, mock-adapter, UI, localization, build, analysis, package, public-history/privacy, and public-copy checks gate this delivery.

The user confirmed correct keyboard changes after reinstalling the preceding local corrected build. This is a manual user report; structured hardware Apply/rollback and Sonoma lifecycle tests remain open. The existing v0.0.9 tag and release assets are retained.

Download the DMG and checksum from this same GitHub release and verify the checksum before opening the image. Quit the old app normally, copy the replacement to Applications, eject the image, and launch. For the expected unidentified-developer block, use System Settings → Privacy & Security → Open Anyway once. Do not disable Gatekeeper or remove quarantine. Stop if the checksum differs or macOS reports damage.
